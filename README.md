# 車輛借用系統

公務車的行車登記系統，從「會議室與車輛借用系統」獨立出來。單一 HTML 檔案，不需要建置工具。
登記版面與紙本「車輛駕駛記錄表」一致：每趟兩行（出發／返回里程與時間）、外觀與車況用 ✓ 或 ✕。

**示範網頁**：<https://evanchi1111-sys.github.io/vehicle-driving-log/>（只有示範資料，資料存在各自的瀏覽器，不會共用）

## 功能

- **返回登記**：用完車後掃車上的 QR Code，一次填完日期、單位、駕駛人、往返地點、出發與返回里程、出發與返回時間、外觀、車況。
- **里程檢查**：顯示上次返回里程，出發里程自動帶入；輸入時即時比對（與上次不符、位數不同、返回小於出發、行駛 0 公里、超過 10 公里）；超過 10 公里送出前再確認一次。
- **外觀、車況**：✓ 正常、✕ 異常。登記為異常後，之後每趟都固定為 ✕，直到管理者在車輛頁標記「已修復」。車況異常必須填說明。
- **補登一筆**：補填忘記登記的行程，須填補登原因，記錄表上標示「補」，並依實際日期排序。
- **管理者修改與刪除**：修改須填原因（標示「改」）；刪除須填原因，並先保留一份刪除紀錄，可在「已刪除的紀錄」還原。
- **單位與使用人名單**：管理者匯入 Excel 或 CSV（欄位：單位、姓名），登記時改為下拉選單，並保留「其他（自行輸入）」。
- **往返地點清單**：管理者維護，登記時為「起點 ↔ 地點」下拉選單。
- **QR Code**：每台車一個，掃描後開啟該車頁面；可下載 PNG。
- **紙本格式匯出**：每台車一份、A4 直式、每頁 18 趟的 HTML，可列印或另存 PDF。
- **備份與還原**（管理者）：備份全部資料為 JSON，還原前先預覽；預設只覆蓋同編號資料，勾選「完全還原」才會刪除備份檔沒有的資料。
- 匯出駕駛記錄 CSV。

## 檔案

| 檔案 | 說明 |
|---|---|
| `app.template.html` | 主程式（供發佈為 Claude Artifact；頁面內容片段，平台會自動加上外層） |
| `index.html` | 完整網頁文件，可直接用瀏覽器開啟或放到靜態網站空間（由 `build.ps1` 產生） |
| `build.ps1` | 由 `app.template.html` 產生 `index.html` |

## 使用方式

### 本機試用（示範模式）

直接用瀏覽器開啟 `index.html`。資料只存在該瀏覽器，不會與他人共用；內建兩台示範車輛（`DEMO-001`、`DEMO-002`）。

### 發佈為 Claude Artifact（多人共用資料庫）

把 `app.template.html` 發佈為 Artifact，並宣告能力：

```json
{
  "db": { "rules": [
    {"path":"vehicleRepairs","read":"view","write":"admin"},
    {"path":"roster","read":"view","write":"admin"},
    {"path":"places","read":"view","write":"admin"},
    {"path":"vehicleDeleted","read":"admin","write":"admin"}
  ]},
  "user": { "scopes": ["profile"] },
  "downloads": true
}
```

- 同仁需要「Contributor」以上權限才能登記，管理者需要「Editor」以上。
- 發佈後，管理者在頁面上新增車輛、匯入單位與使用人名單、設定往返地點，再到車輛卡片按「QR Code」，在「本系統網址」貼上頁面網址後下載 QR Code。
- QR Code 內容為「系統網址＋`#car-<車號>`」。

### 放在 GitHub Pages 等靜態空間

只會是示範模式：每個人的瀏覽器各存各的資料，**不會共用**，也沒有管理者與一般同仁的區分。免費帳號的 GitHub Pages 需要公開倉庫，網址任何人都能開啟。正式給多人使用請用 Claude Artifact 或自行架設後端。

### 搬到自己的伺服器

資料存取集中在資料層的 `put(集合, 物件)`、`del(集合, 編號)`、`subscribe(集合)` 與 `connect()`，改成呼叫自己的 API 即可；其餘畫面與邏輯不需要改。

## 資料集合

| 集合 | 內容 | 寫入權限 |
|---|---|---|
| `vehicles/<車號>` | 車輛基本資料與建檔里程 | 一般登記者 |
| `vehicleLogs` | 行車紀錄 | 一般登記者 |
| `vehicleRepairs` | 外觀、車況修復紀錄 | 管理者 |
| `vehicleDeleted` | 已刪除的行車紀錄（可還原） | 管理者 |
| `roster/current` | 單位與使用人名單 | 管理者 |
| `places/current` | 往返地點清單與起點 | 管理者 |
| `settings/app` | QR Code 使用的系統網址 | 一般登記者 |

## 備份建議

- 每週備份一次、月底多存一份，至少保留 3 份，檔案放在有權限控管的位置。備份檔含人員姓名與行車紀錄，**不要上傳到公開網站或本倉庫**。
- 搬到新環境（新網址或自己的伺服器）前，先備份舊環境，再在新環境用「從備份檔還原」匯入。

## 設定值

- 超過 10 公里需再確認：程式中的 `TRIP_NORMAL_KM`。
- 往返地點的起點預設 `W5`：可在頁面的「往返地點清單」修改。

## 注意

- 修改與刪除按鈕只有管理者看得到，但資料庫層面能登記的人技術上也能改紀錄（登記與修改使用同一份資料）。
- 本倉庫只有程式碼，不含任何真實車輛、人員或行車資料。
